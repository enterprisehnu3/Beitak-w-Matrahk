# منصة بيتك و مطرحك (Beitak W Matrak)

منصة سكن مشترك للمصريين - طلاب وموظفين.

## المتطلبات
- Python 3.8+
- MySQL Database (أو SQLite للتجربة)

## طريقة التشغيل

1. **تثبيت المكتبات المطلوبة:**
   ```bash
   pip install -r requirements.txt
   ```

2. **إعداد قاعدة البيانات:**
   - تأكد من تشغيل MySQL Server.
   - قم بإنشاء قاعدة بيانات باسم `beitak_db`.
   - قم بتعديل ملف `config.py` إذا كان لديك كلمة مرور لـ root أو اسم مستخدم مختلف.
   
   *ملاحظة: إذا أردت التجربة السريعة بدون MySQL، يمكنك تغيير `SQLALCHEMY_DATABASE_URI` في `config.py` إلى `sqlite:///site.db`.*

3. **تشغيل التطبيق:**
   ```bash
   python app.py
   ```
   سيقوم التطبيق بإنشاء الجداول وإضافة بيانات تجريبية (مستخدمين وإعلانات) عند التشغيل لأول مرة.

4. **الدخول:**
   افتح المتصفح على `http://127.0.0.1:5000`
